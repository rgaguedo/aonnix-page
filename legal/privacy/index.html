Política de Privacidad de la Cuenta

Última actualización · 27 de junio de 2026
01

Alcance de esta política

Esta política describe el tratamiento de datos del inicio de sesión opcional ("Cuenta Aonnix") que ofrecen las aplicaciones de Aonnix Dev (división de software de AONNIX E.I.R.L.). El inicio de sesión sirve únicamente para identificar tu cuenta y sincronizar tus compras entre tus dispositivos y plataformas (iOS y Android).

Esta política no describe los datos que maneja cada aplicación internamente (por ejemplo, datos de salud, de loncheras o de mascotas). Para ello, consulta la política de privacidad de cada app (ver sección 8).

02

Datos que recopila el inicio de sesión

Si decides iniciar sesión (con Sign in with Apple o Google), se recopilan los siguientes datos de cuenta a través de Firebase Authentication (Google):

  • Dirección de correo electrónico.
  • Nombre (nombre para mostrar de la cuenta).
  • Identificador de usuario (un ID técnico que representa tu cuenta).

Estos datos son los mismos para todas las apps de Aonnix Dev. El inicio de sesión no solicita permisos adicionales (como contactos, archivos o calendario).

03

Para qué se usan

Los datos de cuenta se utilizan exclusivamente para:

  • Identificar tu cuenta de forma consistente entre tus dispositivos.
  • Recuperar y sincronizar tu compra premium entre dispositivos y plataformas (por ejemplo, de iOS a Android), a través de RevenueCat.

No se utilizan para publicidad, tracking, perfilado ni se venden a terceros.

04

El inicio de sesión es opcional

Las aplicaciones de Aonnix Dev son totalmente utilizables sin iniciar sesión. La cuenta solo se ofrece para recuperar o portar tu compra entre dispositivos; no es necesaria para usar las funciones de las apps.

05

Lo que el inicio de sesión NO hace

  • No accede a los datos internos de las apps (por ejemplo, datos de salud, registros o fotos), que permanecen en tu dispositivo según la política de cada app.
  • No mezcla datos entre apps. Compartir el inicio de sesión solo unifica tu identidad; cada app gestiona sus propios datos y sus propias compras por separado.
  • No realiza seguimiento publicitario ni telemetría con fines de marketing.
06

Servicios de terceros

El inicio de sesión y la gestión de compras se apoyan en:

  • Firebase Authentication (Google): procesa correo, nombre e identificador de usuario para autenticar tu cuenta. Los datos se transmiten de forma cifrada (HTTPS).
  • RevenueCat: gestiona y valida el estado de tu compra premium para permitir su recuperación entre dispositivos y plataformas.
07

Eliminación de la cuenta y tus derechos

Puedes eliminar tu cuenta en cualquier momento desde la propia app, en Ajustes → Cuenta → Eliminar cuenta. Al eliminarla se borran los datos de cuenta asociados (correo y nombre). Tu compra premium no se pierde: permanece en tu cuenta de la tienda (Apple ID / Google) y es restaurable en ese dispositivo.

08

Privacidad de cada aplicación

Para conocer qué datos maneja cada app y cómo, consulta su política de privacidad específica:

  • Privacidad de Crecimiento Infantil
  • Privacidad de Lonchera Fácil
  • Privacidad de Patitas
